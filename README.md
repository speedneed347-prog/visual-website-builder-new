Visual Website Builder

A browser-based visual website frontend builder built with React, TypeScript and Vite.

## Features

- Visual website editing architecture
- Structured document tree
- Basic text, image, video and button elements
- Layout elements including Flexbox and Grid
- Form elements and advanced UI components
- Element selection and document operations
- Responsive device presets
- Undo and redo history utilities
- Local project persistence
- Optional Firebase Authentication and Firestore integration
- HTML, CSS and JavaScript export
- React project export
- ZIP packaging

## Requirements

- Node.js 20 or newer
- npm

npm install
